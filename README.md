# Evil Things: Starfish, Water Tower & Slime

Фанатский аддон для Garry's Mod с тремя оригинальными враждебными энтити и процедурно отрисованными моделями. **Автор этого аддона — автор репозитория; Hospital Gaming — автор Evil API и источник вдохновения, не соавтор и не издатель этого проекта.** Аддон не связан с Hospital Gaming официально и не копирует чужой код, модели, звук или дизайн. Для описания/публикации корректная атрибуция: «Вдохновлено Evil Entities от Hospital Gaming; совместимость с Evil API автора Hospital Gaming». Не указывайте Hospital Gaming как автора этого аддона без его разрешения.

## Существа

- **Evil Starfish** (`evil_starfish`) — красная пятиконечная звезда с движущимися руками и глазами. Быстро преследует игроков, отбрасывает ударом и периодически создаёт ударную волну.
- **Evil Water Tower** (`evil_water_tower`) — высокая башня с баком, опорами, мигающим индикатором и вращающимися линиями давления. Медленная и крепкая; выпускает водяной импульс, который наносит урон и отбрасывает рядом стоящих игроков.
- **Evil Slime** (`evil_slime`) — зелёная полупрозрачная желеобразная масса с пульсацией, глазами и вращающимися каплями. Замедляет при ударе и периодически расплёскивает кислотную слизь.

Модели нарисованы кодом на клиенте из процедурных примитивов; дополнительные модели/материалы не нужны. Анимация пульсации и вращения работает в игре. Это уникальные визуальные модели этого проекта, но пока не отдельные экспортированные `.mdl`-файлы.

## Evil API

Аддон может использовать [Evil API в Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3823740816), опубликованный Hospital Gaming, и API [исходники/документацию](https://github.com/xandwrp/gmod-evil-api). При установленном API существа регистрируются как источники страха для NPC (`Evil.Presence`); при удалении снимают регистрацию (`Evil.Absent`). API остаётся отдельной зависимостью и не включён/не скопирован сюда. Без него существа должны работать с базовым поведением, но без общей системы страха. Подпишитесь на Evil API отдельно и перезапустите игру.

## Как проверить у себя (локально)

1. Скачайте ZIP этого GitHub-репозитория кнопкой **Code → Download ZIP** и распакуйте.
2. Переименуйте распакованную папку, например, в `evil-things` и положите её в папку аддонов GMod:
   - Windows: `.../Steam/steamapps/common/GarrysMod/garrysmod/addons/evil-things/`
   - Linux: `~/.steam/steam/steamapps/common/GarrysMod/garrysmod/addons/evil-things/`
   - Обычно папку игры можно открыть в Steam: Garry's Mod → ⚙ → **Управление → Просмотреть локальные файлы**.
3. Убедитесь, что `addon.json` лежит прямо в `evil-things/`, а внутри есть `lua/autorun/evil_things.lua` и `lua/entities/`. Не должно получиться лишнего уровня вроде `addons/evil-things/имя-репозитория/addon.json`.
4. Запустите GMod, откройте одиночную игру на карте (например, `gm_construct`), нажмите **Q → Entities → Evil Things** и заспавните три существа.
5. Для теста поведения откройте консоль клавишей `~` (при необходимости включите консоль в настройках) и выполните `ent_create evil_starfish`, `ent_create evil_water_tower` или `ent_create evil_slime`. Они ищут ближайшего живого игрока и атакуют в пределах дальности. Для удобного теста используйте локальную игру и не стойте вплотную к башне.
6. Если меню пустое/ошибки: включите консоль разработчика, перезапустите GMod, проверьте `garrysmod/console.log` и убедитесь, что не установлена вторая копия/старая версия аддона. Проверьте каждый раз на чистой карте, сначала без Evil API, затем с подписанным API.

Проверка dedicated server: положите аддон в `garrysmod/addons/` сервера; клиентская отрисовка и Lua должны быть доступны подключающимся игрокам. Интеграцию Evil API для сервера добавьте отдельным Workshop-аддоном/коллекцией.

## Публикация в Steam Workshop

Я не могу загрузить предмет в Workshop от вашего имени: публикация требует вашего Steam-аккаунта и подтверждения прав/соглашений. Перед публикацией добавьте собственное превью, укажите в описании версию, способности, тестированные зависимости и атрибуцию выше. Для названия/описания не создавайте впечатление, что предмет создан или одобрен Hospital Gaming. Следуйте актуальному [руководству Facepunch по Workshop Addon Creation](https://wiki.facepunch.com/gmod/Workshop_Addon_Creation): загрузите папку аддона через инструмент публикации, сначала поставьте видимость Unlisted, проверьте подпиской в игре, затем сделайте Public. Добавьте ссылку на Evil API как необязательную совместимость. Обновляйте существующий Workshop item, не создавая новый.

## Разработка

- Общая серверная логика: `lua/entities/evil_creature_base/`.
- Поведение конкретных энтити: `lua/entities/evil_*/`.
- Процедурные динамические модели: `lua/evil_things/cl_models.lua`.
- Авторские права на сторонний Evil API остаются у его автора. Проект не включает файлы API.
