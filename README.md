# Evil Things — Starfish, Water Tower & Slime

Небольшой аддон для Garry's Mod с тремя оригинальными враждебными энтити. Он вдохновлён общим жанром «злых» существ, но не копирует модели, код, тексты или конкретные способности Hospital Gaming. Модели пока взяты из стандартных ресурсов GMod; позже их можно заменить собственными лицензированными моделями.

## Существа

| Энтити | Способности |
|---|---|
| **Evil Starfish** (`evil_starfish`) | Быстро сближается, отбрасывает при ударе; периодически выпускает круговую ударную волну. |
| **Evil Water Tower** (`evil_water_tower`) | Медленный и крепкий мини-босс; водяной импульс вокруг него наносит небольшой урон и отталкивает игроков. |
| **Evil Slime** (`evil_slime`) | Попадание замедляет игрока на несколько секунд; периодически слизь наносит небольшой урон вокруг себя. |

Ищите их в меню **Q → Entities → Evil Things**. Энтити выбирают ближайшего живого игрока, который находится в пределах видимости. Числа урона, здоровья и дальности задаются в `lua/entities/*/shared.lua`.

## Evil API — совместимость и установка

Да, технически мод можно строить на **Evil API** Hospital Gaming. Ссылка пользователя ведёт к аддону **Evil API** (Workshop ID `3823740816`), а исходный код и документация доступны в [репозитории API](https://github.com/xandwrp/gmod-evil-api). Этот аддон использует API только как необязательную интеграцию: регистрирует существ как источники NPC-страха (`Evil.Presence`) и снимает регистрацию при удалении (`Evil.Absent`). Если API не установлен, существа всё равно работают, но интеграции со страхом NPC не будет. Мы не включаем чужой API-код в этот проект.

Для полной интеграции подпишитесь на Evil API отдельно в Workshop (ссылка дана выше), затем перезапустите GMod. API сторонний и может измениться; перед выпуском проверьте актуальные правила/лицензию его автора и протестируйте его совместно с текущей версией аддона.

## Установка из папки (локальный тест)

1. Скачайте или клонируйте репозиторий.
2. Поместите папку проекта в `garrysmod/addons/evil-things/`.
3. Запустите игру и откройте **Q → Entities → Evil Things**.
4. Для интеграции подпишитесь на Evil API отдельно и перезапустите игру.

Для сервера установите папку в `garrysmod/addons/` сервера. Если сервер использует Workshop-коллекцию, добавьте туда оба аддона: этот и Evil API.

## Публикация в Steam Workshop

У меня нет доступа к вашему Steam-клиенту/аккаунту и права публиковать предмет от вашего имени, поэтому сам загрузить предмет в Workshop не могу. Инструкция для публикации владельцем аккаунта:

1. Установите Garry's Mod и запустите его один раз. Создайте локальную папку аддона с этой структурой: `addon.json`, `lua/autorun/` и `lua/entities/`. **Не загружайте** `.git`, README, временные файлы и архив репозитория.
2. Откройте GMod и используйте инструмент публикации Workshop, если он доступен в вашей сборке/меню игры. Либо установите официальные инструменты Facepunch для создания/загрузки Workshop-аддонов и укажите папку аддона, название, описание, превью и теги. Перед отправкой проверьте актуальные шаги в [официальной инструкции по созданию Workshop addon](https://wiki.facepunch.com/gmod/Workshop_Addon_Creation).
3. Загрузите `addon.json` и Lua-файлы аддона; выберите тип **Addon**, подходящие теги, задайте видимость (сначала **Unlisted** для теста, затем **Public**) и загрузите собственную квадратную картинку-превью в требованиях Workshop.
4. Проверьте предмет в игре через подписку/тестовую коллекцию: отдельно проверьте запуск без Evil API и с ним, спавн всех трёх энтити, урон, удаление и dedicated server.
5. В описании укажите зависимость от **Evil API** со ссылкой `https://steamcommunity.com/sharedfiles/filedetails/?id=3823740816` (она нужна только для совместимости страха NPC), используемые стандартные модели GMod и все известные ограничения. Не выдавайте себя за Hospital Gaming и не используйте чужие арты/модели без разрешения.
6. Для обновления используйте тот же Workshop item/published file ID и инструмент публикации, а не создавайте новый предмет.

Правила и интерфейс Steam могут меняться; следуйте подсказкам Workshop и актуальной документации Facepunch. Для публикации нужны свой Steam-аккаунт, принятые соглашения/условия Steam и права на все загружаемые материалы.

## Разработка

- Lua-файлы лежат в `lua/entities/`.
- Общая логика выбора игрока, движения, атаки и здоровья — `evil_creature_base`.
- Все силы реализованы на сервере; клиентские файлы только отображают модель.
- Проект не содержит ассетов из Evil API или других Workshop-аддонов.

Лицензия проекта ещё не назначена. До публичного выпуска выберите лицензию и проверьте права на любые добавленные вами модели, звуки, превью и код.
